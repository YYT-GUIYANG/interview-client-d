## 3. 建议实测顺序（约 20–30 分钟）

1. 装包并核对 SHA → 打开 App → 设本机测试身份（如 `demo-a`）。
2. 选 **本地 sherpa-onnx** + Q01 → 授权麦克风 → 朗读约 20–40 秒 → 停止 → 看最终文本与关键词 → 保存 → 开档案详情。
3. 杀进程重开 → 同一身份看列表（D-T5）→ 删除一条（D-T6）。
4. （有 B 时）填 WSS → 选 **远程 WSS** → 再说一段 → 确认收尾/`answer_complete` 行为与 PARTIAL 提示。
5. 飞行模式或断网测 D-T4；换另一测试身份确认看不到他人档案。
6. 全程或关键步骤录屏；文件放到本机 `docs/evidence/`（勿把含令牌的画面提交公开仓库时可打码）。
